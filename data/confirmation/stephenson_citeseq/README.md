This directory records the frozen metadata for the Stephenson et al. COVID-19
single-cell multi-omics study, ArrayExpress/BioStudies accession
`E-MTAB-10026` and DOI `10.1038/s41591-021-01329-2`.

The tracked `E-MTAB-10026.sdrf.txt` file is the official 155,174-byte SDRF
served by EMBL-EBI. Its SHA-256 is
`68a27790e45b025f71f445c5ab6dbdc15d5fd74312f8d5366390759ff0580dc5`.
The 7,187,322,881-byte `covid_portal_210320_with_raw.h5ad` payload is acquired
from the same record, verified locally, and is not redistributed in this
repository.

Study authors retain credit and all rights specified by the public study
record. This repository adds only the prospective split, access controls, and
derived aggregate benchmark artifacts.
